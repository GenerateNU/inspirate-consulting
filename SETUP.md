# Inspirate Consulting Repo Setup

1) Install Go:
Follow [this page](https://go.dev/doc/install) to install Go.
Run `go version` to ensure it's installed.

Install Huma (requires Go 1.25 or newer):
Run `go get github.com/danielgtaylor/huma/v2` to install Huma

Install Fiber:
Run `go get github.com/gofiber/fiber/v3`

Install Mockery (for testing):
Run `go install github.com/vektra/mockery/v2@latest`
