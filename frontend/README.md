# Frontend

React 19 + TypeScript frontend, built with Vite and styled with Tailwind CSS.

## Run Locally

```sh
cd frontend
bun install
bun run dev
```

Vite prints the local URL, normally `http://localhost:5173`.

## API Workflow

The backend OpenAPI document is the API contract. After changing a backend route, request model, response model, or API documentation, regenerate the frontend client.

1. Start the backend on port `8080` by running `go run cmd/main.go` in the backend.
2. Save the openapi spec:

   ```sh
   curl http://localhost:8080/openapi.yaml > backend/internal/api/openapi.yaml
   ```

3. From `frontend`, generate the API code:

   ```sh
   bun run generate:api
   ```

`orval.config.ts` reads `../backend/internal/api/openapi.yaml` and generates these files:

- `src/api/endpoints/`: typed request functions and SWR hooks, split by OpenAPI tag.
- `src/api/models/`: TypeScript request, response, and error types.
- `src/api/endpoints/**/*.msw.ts` and `*.faker.ts`: MSW handlers and realistic mock data.
- `src/api/schemas/`: Zod schemas for runtime validation.

Generated files begin with `Generated by orval`; change the OpenAPI document and rerun Orval instead of editing them. Review and commit the refreshed spec and generated output together.

## Using The Generated Client

Import endpoint functions and types from `src/api/endpoints`. The generated client targets `http://127.0.0.1:8080`; ensure the backend is running there during local development.

```tsx
import { createGreeting, type GreetingRequestBody } from '../api/endpoints';

const request: GreetingRequestBody = { name: 'Ada' };
const response = await createGreeting(request);

if (response.status === 200) {
  console.log(response.data.greeting);
}
```

For React mutation state, use the generated SWR hook:

```tsx
import { useCreateGreeting } from '../api/endpoints';

const { trigger, isMutating, error } = useCreateGreeting();
await trigger({ name: 'Bob' });
```
